# DSP Seed Scanner

DSP Seed Scanner is a
[Dyson Sphere Program](https://store.steampowered.com/app/1366540/Dyson_Sphere_Program/)
mod that helps you choose a cluster before starting a new game. Open the
**New Game** preview and the scanner automatically shows strengths, tradeoffs,
and limitations for fresh starts, megafactories, compact expansion, and Dyson
sphere construction. Dark Fog occupation is shown separately.

Use the mouse wheel over either panel to scroll its results. Conclusions name
the relevant systems and planets, while the statistics panel shows resources,
oil rates, moon numbers and useful stars.

Fresh-start guidance covers the starter giant, mineable Fire Ice, power on
neighboring moons and the nearest rich Deuterium supply. Megafactory guidance
highlights nearby systems with useful rare resources or plentiful deposits.
Sphere guidance helps you find nearby luminous stars.

The notable-star table lists blue giants, the brightest star, other O stars
and systems with Aquatica planets near the brightest star. It includes distance,
maximum sphere radius and the number of planets whose orbits fit inside it.
See the [player guide and installation steps](packaging/README.md).

The BepInEx setting `Presentation.PanelCorner` selects the panel corner: `1`
bottom-right (default), `2` bottom-left, `3` top-left, or `4` top-right.

Other BepInEx plugins may be installed alongside DSP Seed Scanner. The scanner
uses the cluster generated by your game; other mods may change that cluster
or affect the scanner's results.

## Development

Build and run the focused core checks with:

```powershell
dotnet build DSPSeedScanner.sln --configuration Release
dotnet run `
  --project tests/DSPSeedScanner.Core.Tests/DSPSeedScanner.Core.Tests.csproj `
  --configuration Release --no-build
```

Building the BepInEx plugin additionally requires the supported local Dyson
Sphere Program installation and BepInEx under the `GameRoot` declared in the
plugin project. Hosted CI uses a narrow compile-only API contract and does not
redistribute game assemblies. Package construction, versioning, and the
integration boundary are documented in the
[Thunderstore package contract](docs/THUNDERSTORE-PACKAGE.md).

Contributors should read [AGENTS.md](AGENTS.md), the authoritative
[project steering document](docs/PROJECT.md), and any scope it authorizes
before changing scope or behavior. Archived plans provide historical context.
